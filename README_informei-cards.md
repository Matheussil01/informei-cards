## <span style="color:#E10600">Sobre o projeto</span>

Projeto front-end de **cards de apresentação** do InforMei, criado para explorar organização visual, estilos e interações com JavaScript. É um projeto complementar à plataforma de gestão voltada a microempreendedores individuais.

## Funcionalidades

- Estrutura de página em HTML
- Estilização dos cards com CSS
- Comportamentos da interface implementados em JavaScript
- Apresentação visual relacionada ao InforMei

## Como executar

Clone ou baixe o projeto e abra `index.html` no navegador.

```bash
git clone https://github.com/Matheussil01/informei-cards.git
```

Os arquivos principais são `index.html`, `style.css` e `script.js`.
